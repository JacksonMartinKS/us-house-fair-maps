# US House Fair Maps

Proposed fair, representative US House maps for all 435 seats: presidential results, implied House results (2016–2026), a what-if slider, demographics and fairness measures.

Static site: `index.html` loads everything from `data/`. Hosted on GitHub Pages; to preview locally run `python3 -m http.server` in this folder and open http://localhost:8000.

Maps and site by Jackson Martin · https://jacksonmartinks.github.io/
